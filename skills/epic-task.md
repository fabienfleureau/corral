## Preconditions of this epic task

This task is one ticket of an epic. Before you change anything, read the ticket's
**Préconditions** / **Preconditions** section, if it has one. Each line is a state
of the world this work needs (a library built and published, a service deployed,
a schema merged). Check each one for real: read the other repository, the registry
or the pipeline, not your assumption.

If a precondition is not met, do not start and do not work around it: report a
question that names the precondition and what you found, then stop. The human
relaunches the task once it holds. If there is no such section, or every line
holds, carry on.
